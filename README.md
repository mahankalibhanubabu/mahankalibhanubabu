I focus on four things:

### 01 — Automate

If a task is repetitive, I look for a way to automate it.

### 02 — Build

I learn by building real applications and infrastructure rather than only following tutorials.

### 03 — Deploy

A project isn't complete just because it works locally. I focus on CI/CD, containers, cloud deployment, and infrastructure.

### 04 — Improve
